# MacleanPhone
Maclean Phone

Maclean Phone is an Android phone application with SIP/VoIP integration for home and business use.

Current Version: 1.2.0
Platform: Android
Package: "com.macleanofduartenterprises.phone"

Features

- Standard Android phone and dialing functions
- SIP/VoIP account integration
- Business IVR automated directory
- English and Russian IVR menus
- Custom IVR directory entries and call routing
- Physical SIM selection for outgoing calls
- Carrier call forwarding
- Multiple forwarding conditions:
  - All calls
  - When busy
  - When unanswered
  - When unavailable
- SIP/VoIP call forwarding
- Voicemail settings
- Manual call recording
- Contacts and Favorites
- Recent call history
- Blocked-number management
- Caller ID announcements
- Notification controls
- Custom appearance and background settings
- Panel opacity adjustment from 1%–100%

Accessibility

Maclean Phone includes built-in accessibility controls, including:

- TalkBack support
- Text scaling from 100%–200%
- Large Controls
- High Contrast
- Visual incoming-call alerts
- Caller announcements
- Simplified Mode
- SIP/VoIP noise and echo reduction
- Hearing-device routing support

Simplified Mode provides large buttons for:

- Favorites
- Keypad
- Recent Calls
- Voicemail
- Settings

SIP/VoIP and Business IVR

Maclean Phone includes an integrated SIP/VoIP system for configuring internet-based calling.

The Business IVR can provide an automated directory for incoming SIP/VoIP calls, including English and Russian language selections and configurable call-routing options.

Example:

"Press 1 for English"
"Press 2 for Russian"

Directory entries can then route callers according to the configured IVR settings.

Calling Accounts

Maclean Phone allows outgoing calls to use:

- Android's default calling account
- Ask which SIM to use for each call
- A selected physical SIM
- Configured SIP/VoIP services where applicable

SIP/VoIP registration status can also be viewed from within the application.

Call Recording

Call recording is manually controlled.

Recording remains off until the user selects Start Recording during a supported call.

Call-recording availability can depend on the Android device, Android version, call type, and manufacturer restrictions.

Installation

1. Download the latest APK from the GitHub Releases section.
2. Allow your Android device to install applications from the source you used to download the APK.
3. Open the APK.
4. Select Install.
5. Open Maclean Phone and grant the required phone, contact, microphone, notification, and call-related permissions.
6. Set Maclean Phone as the default phone application when prompted if you want to use its full cellular calling features.

Updating

Install a newer Maclean Phone APK directly over the existing installation.

Do not uninstall the previous version first if you want to retain your existing application, SIP/VoIP, calling-account, appearance, and phone settings.

Important Notes

Carrier call-forwarding codes are carrier-specific. Your mobile carrier must support the selected forwarding feature and activation code.

Cellular noise processing is controlled by Android and the phone hardware. Maclean Phone's in-app noise and echo reduction controls apply to its SIP/VoIP audio engine.

Hearing-device routing also depends on the audio routes made available by Android and the connected device.

Call recording may not be available on every device or call type.
